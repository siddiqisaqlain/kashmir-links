# Kashmir Links

A link page for Saqlain Siddiqi. The background is a live painting of Kashmir that follows the real date and time through Sonth (spring), Grishm (summer), Harud (autumn) and Wandh (winter).

Single static file, no build step. Edit the `LINKS` list near the top of the script in `index.html` to change the links. A link with an empty `url` stays hidden.

Publish on GitHub Pages: Settings, Pages, deploy from branch `main`, folder `/ (root)`.
